Alita wertet medizinische Bildgebung aus. Auf ihr arbeitet Clara, ein lokales Sprachmodell, als Ausführende — mit einer Wache als einzigem Weg nach draußen und einer gemeinsamen Tafel, über die sie und Claude, das Cloud-Modell, miteinander reden, ohne dass Patientendaten die Maschine verlassen.

Alita analyses medical imaging. On her runs Clara, a local language model, as the executing agent — with a guard as her only way out and a shared blackboard through which she and Claude, the cloud model, talk to each other, without patient data ever leaving the machine.

Wie es zusammenhängtHow it fits together

Der Gedanke, der das Ganze trägt: abnahme beurteilt ein Ergebnis nicht mit einem Modell, sondern zählt nachprüfbare Tatsachen — 170 Dateien da oder nicht, Spalte vorhanden oder nicht. Damit wandert Urteilsfähigkeit aus dem Modell in ein Textdokument, und das lässt sich aufbewahren und wiederverwenden.

The idea that carries the whole thing: abnahme does not judge a result with a model. It counts checkable facts — 170 files present or not, column there or not. Judgement moves out of the model into a text document, and a text document can be kept and reused.

Drei Fehler, die aussahen wie ErfolgThree failures that looked like success

Sie sind der Grund, warum dieses Verzeichnis existiert. Jeder war lautlos.

They are the reason this directory exists. Each one was silent.

1. Eine Datei mit drei ZeichenA three-character file

current-quant stand auf q5. Q5 hat 32 768 Kontext, das Agentenframework verlangt 64 000 und verweigert den Start. Sichtbar wurde das als Runden von 22, 30 und 9 Minuten, die 63, 0 und 57 Byte Log erzeugten. Sieben steckengebliebene Aufträge, null abgeschlossene. Modell, Daten und Aufgabe waren in Ordnung.

current-quant said q5. Q5 has a 32,768-token context; the agent framework requires 64,000 and refuses to start. It showed up as rounds of 22, 30 and 9 minutes producing 63, 0 and 57 bytes of log. Seven stuck jobs, zero completed. Model, data and task were fine.

2. Eine Wache, die nie bellen konnteA watchdog that could never bark

root ::= "ok_weiter"
       | "eskalation_cloud"

Dieser llama.cpp-Build lehnt den Zeilenumbruch vor dem Strich ab — HTTP 400, failed to parse grammar, bei jedem einzelnen Aufruf. Und der Rückfall bei jedem Fehler war ok_weiter. Sie hätte für immer „alles in Ordnung“ gesagt, ohne Fehlermeldung, ohne Log. Eine Wache, deren Ausfall wie Zustimmung aussieht, ist schlimmer als keine, weil sie Vertrauen erzeugt. Behoben; unentschieden ist jetzt ein eigenes Ergebnis.

This llama.cpp build rejects the line break before the bar — HTTP 400, failed to parse grammar, on every single call. And the fallback on any error was ok_weiter. It would have said “all fine” forever, with no error and no log. A watchdog whose failure looks like approval is worse than none, because it creates trust. Fixed; undecided is now a separate outcome.

3. FreeSurfer, unsichtbar für den AgentenFreeSurfer, invisible to the agent

agent.sh startet Clara über sg — setgid, und der dynamische Linker verwirft bei setgid-Programmen jede LD_*-Variable. LD_LIBRARY_PATH kam leer an, also starben recon-all, mri_convert, samseg und mri_synthseg an einer fehlenden ITK-Bibliothek — obwohl sie im PATH standen. Der Selbsttest meldete FreeSurfer als „ok“, weil er ohne sg läuft. Ein grüner Test und ein blinder Agent.

agent.sh starts Clara through sg — setgid, and the dynamic linker discards every LD_* variable for setgid programs. LD_LIBRARY_PATH arrived empty, so recon-all, mri_convert, samseg and mri_synthseg died on a missing ITK library — although they were on PATH. The self-test reported FreeSurfer as “ok” because it runs without sg. A green test and a blind agent.
